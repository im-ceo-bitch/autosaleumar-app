# Unified server
The native app no longer deploys an independent Worker. The web repository contains the single `autosaleumar-backend` Worker and all D1/R2 migrations. Native catalog uses https://api.autosaleumar.com/v1/cars; legacy website API endpoints are handled by the same Worker on https://autosaleumar.com. Disable/replace the old deploy-app-api workflow separately. No previous Cloudflare data or signing assets are needed.
